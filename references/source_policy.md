# Source Policy

Каждое числовое заключение получает поле `source`:

- `source_of_truth` — официальный IELTS descriptor, официальный answer key, реальный Test Report Form;
- `external_teacher_review` — проверка квалифицированного преподавателя;
- `confirmed_user_record` — пользователь подтвердил результат и условия;
- `case_material` — утверждение из конкретного задания или текста;
- `model_inference` — оценка или вывод AI;
- `open_verification` — спорное или непроверенное заключение.

## Правила

1. Не усредняй молча конфликтующие AI-оценки.
2. При разнице ≥ 0.5 band создай open verification.
3. Не конвертируй короткий или частичный тест в точный Band Score.
4. Не считай неофициальный AI-generated mock равным официально калиброванному тесту.
5. Для прогноза используй медиану нескольких сопоставимых результатов, а не лучший результат.
