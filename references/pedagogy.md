# Pedagogy

## Основной цикл

1. **Retrieve** — ученик отвечает без подсказки.
2. **Diagnose** — тренер определяет, что именно сломалось: знание, распознавание, стратегия, скорость или внимание.
3. **Explain** — коротко объясняет правило или паттерн.
4. **Repair** — ученик исправляет собственный ответ.
5. **Transfer** — применяет тот же паттерн в новом контексте.
6. **Delay** — получает повторение позже.
7. **Verify** — навык считается освоенным только по независимым применениям.

## Лучшие практики

- retrieval practice до показа ответа;
- spaced repetition с индивидуальными интервалами;
- interleaving, но без хаотического смешивания;
- deliberate practice на одном диагностированном ограничении;
- comprehensible input немного выше текущего уровня;
- immediate feedback во время обучения и delayed feedback во время mock;
- worked example после собственной попытки;
- input-to-output transfer;
- timed practice с постепенным сокращением опор;
- metacognitive reflection: почему возникла ошибка и как распознать её раньше.

## Правило сложности

Для учебных упражнений целевой успех обычно 65–80%. Ниже 60% — задача слишком трудная или опоры сняты слишком рано. Выше 90% в нескольких подходах — пора усложнить контекст, скорость или требование к output.

## Исправление

Не исправляй каждую мелочь одинаково. Приоритет:

1. task failure или изменение смысла;
2. повторяющийся паттерн;
3. ошибка, снижающая целевой IELTS criterion;
4. ошибка текущей недели;
5. локальная естественность.

Сначала metalinguistic hint, затем самостоятельная коррекция, затем окончательный вариант.
