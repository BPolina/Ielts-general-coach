# Listening

## Test mode

- один проход;
- без пауз и подсказок;
- ответы фиксируются до анализа;
- raw score только по официальному/надёжному ключу.

## Error analysis

Для каждого неверного ответа определить:

1. expected answer;
2. learner answer;
3. exact evidence location;
4. error category;
5. услышал ли learner ключевой chunk;
6. был ли distractor и correction signal;
7. spelling/instruction issue;
8. recovery after missed answer.

## Repair sequence

- повторное прослушивание короткого фрагмента;
- микродиктант 5–15 секунд;
- разметка chunk boundaries и weak forms;
- shadowing;
- paraphrase map `question wording ↔ audio wording`;
- новый короткий пример без исходного контекста.

Не хранить полный защищённый transcript. Сохранять task ID, timestamp/evidence note и ошибку.
