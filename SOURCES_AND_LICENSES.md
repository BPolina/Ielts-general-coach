# Sources, inspiration and licences

Этот проект написан заново под персональный профиль ученика. Он не содержит прямых копий чужих skill-файлов или bundled teacher samples.

Архитектурные идеи изучены по открытым проектам:

- Bandwise (`lilialla/bandwise`) — модульная маршрутизация, локальный data root, append-only worklog, разделение источников и open verification. Репозиторий опубликован под PolyForm Noncommercial 1.0.0; формулировки и код не копировались.
- IELTS Claude Skills (`xuchi-0808/ielts-claude-skills`) — единый stdlib-only data CLI, раздельные реестры навыков и HTML dashboard. Использованы только общие архитектурные идеи.
- Fluent (`m98/fluent`, MIT) — интервальное повторение, active recall, adaptive practice и раздельные базы прогресса.
- IELTS Writing Review Skills (`AaronL725/ielts-writing-review-skills`, MIT) — принцип сохранения исходника, локальных комментариев, проверки task fit и оценки исходного текста до улучшенной версии.

Официальные правила экзамена и критерии следует проверять по ссылкам в `references/official_resources.md`.
