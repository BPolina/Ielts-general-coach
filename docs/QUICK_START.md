# Quick Start

1. Запустите `python scripts/coach_cli.py init`.
2. Проверьте `python scripts/coach_cli.py validate`.
3. Подключите корневую папку как skill/project context.
4. Напишите: `Начать диагностическую неделю`.
5. После каждого занятия используйте skill в том же data root.
6. Раз в неделю создавайте dashboard: `python scripts/coach_cli.py dashboard`.

Точная дата экзамена пока не указана. После бронирования внесите её в `config/student_profile.json`.
